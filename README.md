# Meowgic Snake 🐱🐟

A cat-themed Snake game from WhiskerWorks Arcade. Guide your growing cat through the garden and catch every tasty fish.

**Live:** https://snakitty.vercel.app

## Controls
- Arrow keys or WASD to move
- Swipe on touch screens

## Run locally
No build step. Open `index.html` in a browser, or run:

    npx serve .

## Deploy
Import this repo in Vercel as a static site (Framework preset: Other). Every push to `main` redeploys.
